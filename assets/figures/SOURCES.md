# Paper figure sources

Figures are reproduced from [ModularRSI, arXiv:2609.14857v1](https://arxiv.org/abs/2609.14857v1), accessed on 2026-09-22.
The original figure PDFs come from the [arXiv source archive](https://arxiv.org/src/2609.14857v1).

| Local asset | Paper location | Source archive member |
| --- | --- | --- |
| `modularrsi-overview` | Figure 1, page 4 | `figure/main.pdf` |
| `harness-architecture` | Figure 5, page 16 | `figure/harness_architecture.pdf` |
| `evolution-data-distribution` | Figure 2, page 7 | `figure/evolution_data_distribution.pdf` |

The PDF files are unchanged originals. PNG files render the complete figures at
1,800 pixels wide using PyMuPDF on an opaque white background. No cropping,
recoloring, relabeling, or data changes were applied. The overview includes
embedded raster artwork in its original PDF; rendering does not add source detail.

`evolution-data-distribution.csv` transcribes the category counts from Figure 2.
The Algorithms SWE count is 14, the difference between its labeled total (176)
and Terminal count (162). Counts sum to 1,000 tasks per domain and 2,000 overall.
The CSV contains aggregate counts, not individual task records.
